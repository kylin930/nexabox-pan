NexaboxDrive API 接口文档

内部版本 | 个人空间 + 资源池版 | v2.1 用户数据隔离 · 共享资源池 · 旧数据清理

一、 全局鉴权说明

所有私有接口请求均需要通过 HTTP Header 传递 Token 进行身份验证。公共分享接口无需此 Header。

Header 键 格式与说明
Authorization Bearer <您的Token>

二、 核心流程详细说明

1. 批量与文件夹上传 (Batch & Folder Upload) Update

前端通过解析 webkitRelativePath 实现保留层级的上传：

  • 递归建权： 若上传的是文件夹，前端会自动检查并调用 /api/folder 逐级创建虚拟目录。
  • 并发上传： 多个文件可以并发执行切片上传流程，每个文件上传完成后独立提交元数据。

2. 字段统一规范 (Data Consistency) New!

为保证前端渲染稳定性，所有文件/目录对象必须包含以下字段：

  • isFolder: 布尔值，标识是否为文件夹。
  • path: 字符串，标识所属的绝对父级虚拟路径（如 /Photos/）。

3. 全局搜索逻辑 (Global Search)

搜索接口仅扫描当前登录用户个人空间内的记录，匹配文件名中的关键字（不区分大小写），并返回跨目录的匹配结果。无法搜索到其他用户的文件。

4. 个人空间数据隔离 (Per-User Isolation) New!

自 v2.0 起，网盘由共享空间改为每人一个独立空间：

  • 数据键规则： 文件/文件夹记录按用户隔离存储，键前缀为 user:<用户名>:file: 与 user:<用户名>:dir:。
  • 分享记录： 全局键 share:<id>，内含归属人（owner）与源 fileId，公开接口据此回到归属人空间取数。
  • 权限边界： 列表/搜索/下载只作用于本人空间；分享接口会校验 fileId 归属，禁止分享他人文件。
  • 资源池： pool: 前缀为全员共享空间，与个人空间互相独立，任何拥有网盘权限的用户均可上传/查看/下载/分享，详见接口 8。
  • 旧版数据： 旧共享空间数据（FILE_ / SHARE_ 前缀）已废弃，管理员可通过 /api/purge-legacy 一次性清空。

三、 接口列表

1. 全局搜索 (Search Files)

  • 接口路径： /api/search
  • 请求方式： GET
  • 查询参数： keyword (必填，搜索关键字)；scope (可选，pool 时搜索资源池，默认搜索个人空间)
返回示例： 
[
  {
    "id": "FILE_1714000000001",
    "filename": "工作报告_2024.pdf",
    "isFolder": false,
    "path": "/Documents/Work/",
    "size": 204800,
    "chunks": ["..."]
  }
]

2. 获取文件列表 (List Files)

  • 接口路径： /api/files
  • 请求方式： GET
  • 查询参数： path (可选，默认为 /)

3. 创建文件夹 (Create Folder)

  • 接口路径： /api/folder
  • 请求方式： POST

4. 创建分享链接 (Create Share)

  • 接口路径： /api/share
  • 请求方式： POST
  • 说明： 可分享个人空间内自己的文件/文件夹，或资源池内的任何内容。

5. 获取公共分享信息 (Get Public Share Info)

  • 接口路径： /api/public/share
  • 请求方式： GET / POST
  • 说明： POST 验证后，若为文件夹则返回 children 数组，且每个子项均包含规范化的 path 与 isFolder 字段。

6. 获取当前用户信息 (Who am I) New!

  • 接口路径： /api/me
  • 请求方式： GET
返回示例： 
{
  "username": "alice",
  "permissions": ["NexaboxDrive"]
}

7. 清空旧版共享数据 (Purge Legacy Data) New!

  • 接口路径： /api/purge-legacy
  • 请求方式： GET（查询剩余条数）/ POST（执行清空）
  • 说明： 删除旧版共享空间 FILE_ / SHARE_ 前缀的全部 KV 记录，不影响任何用户的个人空间数据。POST 仅限拥有 all 权限的管理员调用。

8. 资源池 (Resource Pool) New!

  • 接口路径： /api/pool
  • 请求方式： GET（列取资源池内容，查询参数 path 可选）/ POST（保存文件元数据或创建文件夹）
  • 说明： 资源池为全员共享空间，所有拥有网盘权限的用户均可上传、查看与下载。POST 时传 isFolder: true 即创建文件夹；服务端自动记录 uploader（上传者）字段用于溯源。数据键为 pool:file: / pool:dir: 前缀，与个人空间完全隔离。

四、 客户端接入示例 (C#)

1. C# 全局搜索示例

public async Task<List<FileItem>> SearchAsync(string keyword)
{
    var response = await client.GetAsync($"{API_BASE}/api/search?keyword={Uri.EscapeDataString(keyword)}");
    response.EnsureSuccessStatusCode();
    var json = await response.Content.ReadAsStringAsync();
    return JsonSerializer.Deserialize<List<FileItem>>(json);
}
